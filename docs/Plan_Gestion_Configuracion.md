**Plan de Gestión de Configuración del equipo
El grupo partirá de estas reglas como base para la gestión del proyecto 

• Rama principal.
• Convención de ramas y commits.
• Flujo de trabajo trazable.
• Política de revisión.
• Protección de main.
• Tratamiento básico de conflictos.
• Archivos excluidos (.gitignore).
• Procedimiento de integración.

El desarrollo del proyecto contempla unas normas a la hora de aplicar los cambios, estas son:

1-  No push directo a main.
2-  Todo cambio relevante tiene trabajo asociado.
3-  Todo cambio que afecte a main llega por PR.
4-  Toda PR relevante la revisa por persona.
