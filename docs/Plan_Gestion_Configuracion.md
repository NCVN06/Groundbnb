# Política de cambios
El desarrollo del proyecto contempla unas normas a la hora de aplicar los cambios.

-  No push directo a main.
-  Todo cambio relevante tiene trabajo asociado.
-  Todo cambio que afecte a main llega por PR.
-  Toda PR relevante la revisa por persona.
